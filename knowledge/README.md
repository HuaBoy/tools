# 📚 本地RAG知识库系统

## 🎯 概述

这是一个基于浏览器的本地检索增强生成（RAG）知识库系统，完全在浏览器中运行，无需服务器端依赖。系统支持智能搜索、文档导入、向量化存储和语义检索。

## ✨ 核心特性

### 1. **智能语义搜索**
- 基于向量相似度的语义搜索
- 支持自然语言问题查询
- 按相关性排序结果
- 相似度评分显示

### 2. **多格式文档支持**
- 📄 **文本文件** (.txt, .md)
- 📊 **PDF文档** (需要浏览器支持)
- 📝 **Word文档** (.docx)
- 📋 **JSON数据**

### 3. **本地存储**
- 向量数据存储在浏览器 localStorage
- 支持数据持久化
- 支持导入/导出功能
- 离线可用

### 4. **高级功能**
- 智能文档分块处理
- 语义向量嵌入
- 分类和标签管理
- 搜索历史记录

## 📁 项目结构

```
knowledge/
├── vector_db/          # 向量数据库（浏览器存储）
├── documents/          # 文档存储目录
│   ├── raw/           # 原始文档
│   └── processed/     # 处理后的文档分块
├── sqlite/            # SQLite数据库（预留）
├── cache/             # 模型和缓存
└── README.md          # 说明文档
```

## 🔧 技术架构

### 核心模块
1. **文本嵌入模块** (`embedding.js`)
   - 使用 SentenceTransformers 模型
   - 支持中文语义理解
   - 384维向量空间

2. **向量存储模块** (`vectorStore.js`)
   - 内存向量存储
   - 快速相似度计算
   - 本地持久化

3. **文档处理模块** (`documentProcessor.js`)
   - 多格式文档解析
   - 智能文本分块
   - 关键词提取

4. **知识库管理器** (`knowledgeManager.js`)
   - 统一API接口
   - 数据管理
   - 搜索功能

## 🚀 快速开始

### 1. 安装依赖
```bash
# 安装RAG相关依赖
npm install @xenova/transformers pdf-parse
```

### 2. 访问知识库
1. 启动项目：`npm run dev`
2. 访问：`http://localhost:3000`
3. 导航到：**AI知识库 > 智能知识库(RAG)**

### 3. 添加知识条目
1. 点击"新增知识"按钮
2. 输入问题描述和解决方案
3. 选择分类标签
4. 点击"保存入库"

### 4. 导入文档
1. 点击"导入文档"按钮
2. 选择支持的文档格式
3. 设置分类标签
4. 点击"开始导入"

### 5. 智能搜索
1. 在搜索框输入问题描述
2. 按Enter或点击搜索按钮
3. 查看相关度排序的结果

2. **关键词**：使用相关术语

4. **相似度阈值**：默认30%以上相关度

## ⚙️ 配置选项

### 向量模型配置
```javascript
// src/modules/rag/embedding.js
const modelConfig = {
  modelName: 'Xenova/all-MiniLM-L6-v2', // 轻量级模型
  vectorSize: 384,                      // 向量维度
  cacheDir: './knowledge/cache/models'   // 模型缓存目录
}
```

### 搜索参数
```javascript
const searchOptions = {
  topK: 10,           // 返回结果数量
  minScore: 0.3,      // 最小相似度阈值
  includeAnswer: true // 是否包含答案
}
```

### 文档处理
```javascript
const processingConfig = {
  maxChunkSize: 1000,  // 最大分块字符数
  chunkOverlap: 200,   // 分块重叠字符数
  supportedFormats: ['txt', 'pdf', 'docx', 'md', 'json']
}
```

## 🔍 搜索算法

### 向量搜索流程
```
用户问题 → 文本清洗 → 向量嵌入 → 向量相似度计算 → 结果排序 → 返回TopK
```

### 相似度计算
- **余弦相似度**：向量空间角度计算
- **语义理解**：基于预训练模型
- **多维度匹配**：问题+答案综合评分

## 💾 数据管理

### 存储位置
- **向量数据**：浏览器 localStorage
- **文档数据**：内存存储 + 本地文件系统
- **元数据**：JSON格式存储

### 数据导出
- **JSON格式**：完整知识库数据
- **CSV格式**：表格化导出
- **备份恢复**：支持数据迁移

## 🔧 故障排除

### 常见问题

#### 1. 搜索无结果
- 检查搜索关键词
- 调整相似度阈值
- 确保知识库中有数据

#### 2. 文档导入失败
- 检查文件格式是否支持
- 确认文件大小不超过10MB
- 检查浏览器权限

#### 3. 浏览器兼容性
- **推荐**：Chrome 87+, Edge 88+, Firefox 78+
- **需要**：WebAssembly 支持
- **建议**：启用 localStorage

### 性能优化
1. **模型缓存**：首次加载后缓存模型
2. **向量索引**：建立快速检索索引
3. **分批处理**：大文档分批次处理
4. **内存管理**：定期清理缓存

## 📈 性能指标

### 搜索性能
- **向量生成**：~50ms/文档
- **相似度计算**：~1ms/向量
- **结果排序**：O(n log n)

### 存储容量
- **向量存储**：~1.5KB/文档
- **文本存储**：按实际大小
- **浏览器限制**：5-10MB（localStorage）
