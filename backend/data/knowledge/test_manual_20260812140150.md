# 起爆器故障排查手册

## 1. 设备无法连接

当起爆器无法与电脑连接时，请依次检查：

1. 确认 USB 数据线已正确插入，尝试更换数据线
2. 确认设备已开机，指示灯为绿色
3. 打开设备管理器，查看是否识别到未知设备
4. 安装最新版本的 USB 驱动，重启电脑后重试

如果以上步骤都无效，请联系技术支持并提供设备序列号。

## 2. 授权码验证失败

如果授权码验证失败，请按以下步骤处理：

1. 确认授权码未过期
2. 确认输入的授权码无多余空格和特殊字符
3. 确认授权码与设备硬件绑定匹配
4. 联系销售重新申请授权码

## 3. 通信故障排查

当起爆器与软件通信异常时：

1. 检查串口号是否正确选择
2. 检查波特率是否设置为 115200
3. 检查是否有其他软件占用串口
4. 尝试重新插拔 USB 线

## 4. 日志解析异常

日志解析出现异常时：

1. 确认日志文件格式为 CSV 或 TXT
2. 确认日志文件未损坏
3. 检查日志文件编码是否为 UTF-8
4. 尝试用记事本打开日志文件确认内容可读
