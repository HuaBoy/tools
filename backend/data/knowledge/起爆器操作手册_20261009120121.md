# 起爆控制器（起爆器）操作手册

> 本文档适用于本工具集配套的起爆控制器（手持起爆器 / 现场控制器）。所有操作须严格遵守国家爆破安全法规与现场作业规程，由持证爆破作业人员执行。

## 1. 设备组成

- 主机：集成显示屏、按键/触控、通信模块。
- 电源：内置可充电锂电池，支持外接电源充电。
- 通信接口：用于与雷管组网（无线/总线）、与手持采集器/上位机通信。
- 状态指示灯：电源、充电、组网、起爆四色指示。

## 2. 开机与自检

1. 长按电源键 3 秒开机，进入系统自检。
2. 自检项包括：电量、时钟、通信模块、内部存储。
3. 自检通过后进入主界面；若某项异常，界面会给出具体提示，需排除后再作业。

## 3. 充电与电量管理

- 使用原装充电器，充电时指示灯常亮为充电中，转绿为充满。
- 建议作业前电量不低于 60%；低温环境电量消耗加快，需预留余量。
- 长时间不使用，应每 30 天充电一次，防止电池过放。

## 4. 组网流程

1. 在主界面选择「组网检测」。
2. 控制器依次与已录入的雷管建立通信，读取每发雷管的 UID 与状态。
3. 组网完成后显示在线数量与离线清单，离线雷管需现场排查后重新组网。
4. 在线数量须与计划一致，方可进入起爆准备。

## 5. 起爆准备与执行

1. 确认所有人员已撤离至安全区，警戒到位。
2. 在软件中核对起爆顺序、延期时间、雷管数量。
3. 输入起爆授权口令（由现场负责人下发）。
4. 倒计时结束后执行起爆；起爆结果（成功/失败清单）自动记录并上传。

## 6. 安全注意事项

- 起爆器仅限持证人员在合规作业中使用。
- 起爆前必须完成组网检测与数量核对，禁止带病起爆。
- 出现通信异常、电量不足、雷管离线等情况，立即停止作业并排查。
- 起爆记录应妥善保存，用于追溯与复盘。
